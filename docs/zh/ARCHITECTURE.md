# 架构与安全

[首页](README.md) · [英文规范](../../ARCHITECTURE.md)

应用使用 Avalonia 界面、MVVM 命令协调以及负责签名、存储、设置和桌面集成的服务。签发方保留私钥，客户端只接收公钥。

创建页面时不会读取许可证存储。导航先显示页面，再等待可取消的加载，并保留页面实例以保存表单草稿。视图模型在线程池中执行存储操作，然后在界面上下文中更新可观察状态。操作进行时会阻止重复修改。已经开始的写入会完成；编辑表单只会使显示的结果失效，不会丢失已保存的许可证。

存储读取服务在同一个存储锁内读取产品与历史记录，并返回包含这些数据的 `WorkspaceSnapshot`。仪表盘使用这份一致的数据计算统计值，并提示被跳过的损坏记录。列表保留筛选结果，翻页时不会重新读取存储。

`AdaptiveGrid` 负责界面布局：测量可见元素，根据可用宽度和文字大小调整列数。确认对话框具有模态行为，初始焦点位于“取消”，关闭后恢复原先的焦点。视图模型通过 `IDialogService` 请求确认，以便分别测试确认和取消操作。

[统一规范](../../ARCHITECTURE.md) 定义 JSON 类型、被签名的字节、格式版本和验证规则。[C# 验证器](../examples/LicenseVerifier.cs)及其[共享协议](../examples/LicenseProtocol.cs)与应用一同编译和测试；集成时请复制这两个文件。

- 许可证是经过 Base64 编码的 UTF-8 JSON，不是加密数据。
- 签名算法为 RSA-2048、SHA-256 和 PKCS#1 v1.5。
- UserDefined 为空时保持旧格式，不输出新属性。
- 非空 UserDefined 使用格式 2，需要更新客户端。
- 拒绝未知版本及不一致的字段组合。格式 2 验证失败后不得回退到旧格式。
- 旧格式拒绝文本字段中的 `|`，避免字段边界歧义。
- 到期时间为指定日期**开始时的 UTC 00:00**。每次访问判断都应重新验证。
- HardwareId 为空表示不绑定设备；非空时必须完全匹配。

检查器使用同一份验证代码。`TryVerify` 保留布尔返回值契约；`Inspect` 返回不含已认证字段的拒绝结果，或已认证的数据及独立的产品、硬件和到期检查结果。未提供预期 HWID 时，绑定硬件的许可证会标记为**未检查**，不会视为有效。签名不匹配无法区分公钥错误与数据被篡改。用户必须明确选择本地产品的公钥，或粘贴来自可信来源的公钥；绝不根据收到的 JSON 自动选择可信密钥。检查不会写入历史记录、连接服务器或提供撤销功能。

数据位于 `<LocalApplicationData>/LicenseGenerator/`，包括 `Keys`、`Licenses`、`settings.json` 和 `Logs`。ZIP 备份未加密。导入会添加缺失数据、拒绝冲突，并以原子方式替换有效设置。

离线签名无法阻止客户端代码或系统时钟被修改。远程撤销需要额外机制。请参阅[安全边界](../../ARCHITECTURE.md#security-boundaries)和 [EULA](../../LICENSE)。
