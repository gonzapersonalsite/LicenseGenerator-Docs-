# Security reports

Report a suspected vulnerability privately using
[Report a vulnerability](https://github.com/gonzapersonalsite/license-generator-docs/security/advisories/new).
Do not disclose exploit details in a public issue while the report is being assessed.

Include the affected app version, operating system, installation source, impact
and minimal reproduction steps with invented data. Never include real signing
keys, customer licenses, passwords or unencrypted backups.

Security fixes target the current release. Historical downloads remain available
for compatibility; their availability is not a promise of ongoing maintenance.
See the [latest release](https://github.com/gonzapersonalsite/license-generator-docs/releases/latest)
and the [security contract](ARCHITECTURE.md) for supported verification behavior
and the limits of offline licensing.
